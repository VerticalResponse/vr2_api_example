Connect an application

Paste the credentials of an application registered in VerticalResponse. It has to be a Delegated app, and its registered Redirect URI has to be exactly the one shown above — the provider compares those two strings for equality, with no wildcards and no tolerance for a trailing slash.

Held in memory for this browser session and nowhere else. It is never written to disk and never put in the cookie.

What happens next

  1. This app generates a random state and redirects your browser to the consent screen on the provider.
  2. You approve, and the provider redirects back to {{.Config.Redirect}} with a code and the same state.
  3. This app checks the state, then exchanges the code for an access token and a refresh token — a back-channel call, through the gateway, carrying the client secret.

Before you start

This one needs no token, so it answers whether or not anything above has worked yet. If it comes back and the console does not, the token is the problem rather than the routing.
