Revoke this authorization

This sends DELETE {{.Config.Provider}}/api/v1/oauth/revoke with the client credentials and the current refresh token. That endpoint is not in the gateway's endpoint list, so it goes straight to the application host.

The authorization ends immediately and the refresh token stops working, so the next refresh fails with 400 invalid_grant. That code is deliberately broad — it covers a grant that is unknown, expired or revoked alike — so read error_description to see which. The access token you already hold keeps working until it expires: it is a stateless JWT, checked by signature rather than looked up on each request.

The call answers {"status":"ok"} even for a refresh token that does not exist, so a caller cannot use it to discover which tokens are real.
